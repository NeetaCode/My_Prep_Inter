CASE 1 — Legacy Chromatin Reconstruction + Docker
Role: SE / Research Engineering / DevOps

S — Situation
A legacy chromatin reconstruction pipeline had stopped working because the environment and dependencies were outdated.

T — Task
I needed to get the entire model running end-to-end, fix all dependency issues, and containerize the system using only the terminal.

A — Action
• Reverse-engineered the entire codebase and mapped its workflow.  
• Rebuilt the environment and resolved incompatible Python packages.  
• Fixed broken modules and updated outdated API calls.  
• Wrote a Dockerfile from scratch and created reproducible scripts.  
• Validated outputs using test datasets.

R — Result
Successfully restored a nonfunctional research model, making it stable, portable, reproducible, and easy for other researchers to run via Docker.



CASE 2 — Network Troubleshooting & Ticket Resolution
Role: SE / Systems / Networking

S — Situation
I handled incoming network-related tickets across the organization.

T — Task
Diagnose root causes quickly and resolve them without impacting production.

A — Action
• Investigated packet flow, DNS issues, routing failures, and misconfigurations.  
• Used traceroute, ping, Wireshark, and log analysis.  
• Worked with sysadmin and infra teams when escalation was needed.  
• Documented each issue to reduce repeat incidents.

R — Result
Resolved issues within SLA, improved reliability, and reduced repeat tickets through better documentation and root-cause fixes.

CASE 1 — Accent Detection Using ANN, LSTM, BiLSTM
Role: AI/ML / Deep Learning / Speech Processing

S — Situation
Assigned an end-to-end accent detection project without prior experience in audio processing.

T — Task
Build a full deep learning pipeline to classify accents with good accuracy.

A — Action

• Extracted MFCCs, spectrograms, and normalized features.  
• Implemented ANN, CNN, LSTM, and BiLSTM architectures.

R — Result

CASE 2 — RL-Based 3D Chromosome Reconstruction
Role: AI/ML Research / Reinforcement Learning / Computational Biology

S — Situation
Our team wanted to explore reinforcement learning for 3D chromosome structure generation.

T — Task
Design and implement an RL-based model that learns to construct chromosome shapes matching distance constraints.

A — Action
• Studied RL fundamentals, reward shaping, and exploration strategies.  
• Designed an RL pipeline where the agent iteratively refined the 3D structure.  
• Implemented a reward system based on distance accuracy and structural consistency.  
• Visualized predicted vs ground-truth structures.

R — Result
Delivered a working RL proof-of-concept demonstrating RL’s potential in structural genomics.

10. How do you handle stress and pressure?
I handle stress by staying organized and using simple, effective routines. I break my work into smaller tasks, use techniques like the Pomodoro method, and take microbreaks to stay focused. I maintain a clear to do list and work through priorities one step at a time.

I also pay attention to my physical, mental, and emotional limits. When I see that my workload is crossing a healthy threshold, I pause, rest, and return with a fresh mind so I can be productive without burning out. I am learning to communicate clearly and assertively, including saying no or renegotiating timelines when it protects both my well being and the quality of the work.

This approach helps me stay calm, maintain consistency, and deliver high quality results even under pressure.
