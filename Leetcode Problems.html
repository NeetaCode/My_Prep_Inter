15. Topological Sort - Dependency ordering

Meaning

Topological sort orders nodes in a directed acyclic graph so that every edge goes from earlier to later.

Syntax (Python - Kahn's algorithm)

from collections import deque

indegree = {node: 0 for node in graph}
for node in graph:
    for nei in graph[node]:
        indegree[nei] += 1

queue = deque([node for node in graph if indegree[node] == 0])
order = []
while queue:
    node = queue.popleft()
    order.append(node)
    for neighbor in graph[node]:
        indegree[neighbor] -= 1
        if indegree[neighbor] == 0:
            queue.append(neighbor)

Usage

  • Schedule tasks that have prerequisites and dependency constraints.
  • Detect cycles when no full ordering is possible.

16. Union Find - Connectivity and components

Meaning

Union find maintains disjoint sets and quickly answers whether two nodes are in the same component.

Syntax (Python)

def find(x):
    if parent[x] != x:
        parent[x] = find(parent[x])
    return parent[x]

def union(a, b):
    rootA = find(a)
    rootB = find(b)
    if rootA != rootB:
        parent[rootB] = rootA

Usage

  • Count connected components in graphs.
  • Evaluate connectivity after unions for equations or relations.

25. Trie - Prefix search

Meaning

A trie is a tree data structure that stores strings by characters along paths from the root.

Syntax (Python)

class TrieNode:
    def __init__(self):
        self.children = {}
        self.is_word = False


class Trie:
    def __init__(self):
        self.root = TrieNode()

    def insert(self, word: str) -> None:
        node = self.root
        for c in word:
            if c not in node.children:
                node.children[c] = TrieNode()
            node = node.children[c]
        node.is_word = True

Usage

  • Implement fast prefix searches and autocomplete suggestions.
  • Store dictionaries of words and support incremental search.
